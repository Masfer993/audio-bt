# Протокол PhoneAudio (Bluetooth)

Звук: стандартный A2DP. ПК открывает соединение через Windows `AudioPlaybackConnection` (ПК = Bluetooth-колонка),
Android сам направляет звук на подключённый A2DP-приёмник. Захват звука и Wi-Fi не используются.

Управление: Bluetooth RFCOMM (SPP), UUID `6b3f1a52-7c2e-4d5a-9f10-2a8c4e7d1b93`, строки UTF-8, `\n`. Телефон = клиент.

Телефон → ПК            | Ответ
------------------------|------------------------------
`HELLO <имя>`           | `OK open` / `OK closed`
`PING` (каждые 3 с)     | `PONG`
`OPEN`                  | `OK` / `ERR <причина>` (ПК подключает A2DP, до нескольких секунд)
`CLOSE`                 | `OK`
ПК → телефон (без запроса): `STATE open` / `STATE closed` при изменении состояния A2DP.
Тишина >12 с на ПК или обрыв канала: ПК закрывает A2DP, и звук возвращается на телефон.
