# Установка и использование (Bluetooth-версия)

## Один раз
1. Сопрягите телефон с ПК: Windows → Параметры → Bluetooth и устройства → Добавить устройство → Bluetooth, и подтвердите код на обоих.
2. Запустите PhoneAudioReceiver.exe на ПК (значок в трее, возможно под ^). Меню трея → «Запускать с Windows».
3. Установите app-debug.apk на телефон. Откройте приложение → «Настройки» → «Автозапуск» и «Экономия батареи» (нет ограничений).
4. Нажмите большую кнопку: разрешите «Устройства поблизости». Звук телефона пойдёт через ПК за 1-3 секунды.

## Плитка в шторке (Android 12: вручную)
Шторка → карандаш → перетащить «Звук на ПК» в активные плитки.

## Если звук не идёт
Откройте %APPDATA%\PhoneAudioReceiver\log.txt: там список найденных A2DP-устройств и ошибки. Пришлите его.
